# 후한의원 강남점 편평사마귀 랜딩페이지

전주점(`hoo-jeonju-landing`)과 **동일한 틀**로 만든 강남점 전용 사이트입니다.
디자인·구조는 그대로이고, 지점 정보(주소·전화·진료시간·의료진·SEO)만 강남점으로 교체돼 있습니다.

## 🔴 게시 전에 반드시 처리해야 할 것

지금 상태로 인터넷에 올리면 안 됩니다. 아래 6가지를 먼저 채워주세요.
(파일 안에서 `⚠️` 를 검색하면 해당 위치로 바로 갈 수 있습니다)

### 1. 편평사마귀 제거 비용 — `index.html` 「비용 안내」 섹션
강남점 공식 홈페이지에 금액이 공개돼 있지 않아 전부 **"상담 시 안내"** 로 비워뒀습니다.
실제 금액을 알려주시면 넣어드리고, 직접 하실 경우 아래처럼 바꾸시면 됩니다.

```
<span>상담 시 안내</span>   →   <span>25만원</span>
```

금액을 넣은 뒤에는 `<head>` 안의 JSON-LD `"priceRange": "₩₩"` 도 함께 손봐 주세요.

### 2. 전후사진 — `assets/images/case1~4-before/after.svg`
지금은 회색 자리표시 이미지입니다.
**전주점 환자 사진은 강남점 페이지에 쓸 수 없습니다** (촬영 동의 범위 · 의료광고 문제).
강남점에서 동의받은 사진으로 교체하고, 각 카드의 부위·기간·날짜 문구도 실제 사례로 바꿔주세요.

### 3. 의료진 사진 — `assets/images/doctor-hong/min/jung/oh/kang.svg`
후한의원 공식 홈페이지에도 원장님 사진이 올라가 있지 않아 자리표시로 넣었습니다.
5명분 사진을 같은 이름으로 덮어써 주세요.

### 4. 대표 이미지 — `assets/images/hero-main.svg`
첫 화면 큰 사진입니다. 강남점 내부 사진이나 시술 사진으로 교체하세요.

> 실제 사진은 `.jpg` 로 넣으시는 게 좋습니다.
> 그럴 경우 `index.html` 에서 해당 파일명의 `.svg` 를 `.jpg` 로 바꿔주세요.
> (VS Code에서 `Ctrl+F` → `.svg` 검색)

### 5. 공유용 이미지 (og:image)
`<head>` 의 `og:image` 는 `hero-main.jpg` 를 가리키고 있습니다.
카카오톡·페이스북 공유 미리보기는 SVG를 지원하지 않으므로,
4번에서 **반드시 `.jpg` 로** 넣어주셔야 공유 썸네일이 나옵니다.

### 6. 검색엔진 소유확인 코드
`index.html` 맨 위에 주석 처리해 뒀습니다.
네이버 서치어드바이저 · 구글 서치콘솔에서 **강남점 도메인으로** 새로 발급받아 채워주세요.
어드민의 **1. 기본 SEO** 탭에도 입력란을 만들어 뒀습니다.

> ❗ 전주점 코드를 그대로 쓰면 강남 사이트가 전주점으로 잡힙니다. 반드시 새로 발급받으세요.

## 폴더 구조

```
hoo-gangnam-landing/
├─ index.html              # 랜딩페이지 전체
├─ columns.html            # 원장 컬럼 목록
├─ columns/                # 개별 컬럼 (독립 URL = SEO/GEO 단위)
│  ├─ column-01.html ~ column-04.html
├─ assets/images/          # 이미지 (자리표시 → 실제 사진으로 교체 필요)
├─ CNAME                   # 도메인 (지금은 임시값 gnhoowart.co.kr)
├─ robots.txt              # AI 크롤러 허용 설정
├─ llms.txt                # 생성형 AI용 사이트 요약
├─ sitemap.xml
└─ 사이트에-올리기.bat      # 원클릭 업로드 (전주점 저장소 차단 장치 포함)
```

어드민은 이 폴더에 없습니다. 옆의 **`hoo-gangnam-admin`** 폴더에 따로 있습니다.
설치 방법은 그 폴더의 `어드민-설치-순서.md` 를 보세요.

## 도메인 바꾸기

지금은 임시로 `gnhoowart.co.kr` 이 들어가 있습니다. 실제 도메인이 정해지면
아래 파일에서 이 주소를 한꺼번에 바꿔주세요. (VS Code `Ctrl+Shift+F` 로 일괄 변경 가능)

- `CNAME`
- `index.html` (canonical / og:url / og:image / twitter:image / JSON-LD)
- `columns.html`, `columns/*.html`
- `llms.txt`, `robots.txt`, `sitemap.xml`
- `사이트에-올리기.bat` (완료 메시지)
- 어드민의 **1. 기본 SEO → 사이트 도메인** 칸
